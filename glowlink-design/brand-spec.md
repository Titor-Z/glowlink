# 萤光 GlowLink — 视觉系统（brand-spec.md）

**来源**：① Figma 复刻规格文档（数值从 HTML 原型提取，**权威值**） ② `mujspnlx-why.md`（PRD v1.0，产品定位）
**标语**：萤萤之光，可照旷野。
**定位**：闭源、本地优先、去中心化的跨平台近场文件传输网络。320×500 无边框小窗 + 动态节点图。

## 二、字体

- 显示 / 正文：SF Pro（`-apple-system` / `SF Pro Text`），中文回退 `PingFang SC`。
- 数值：产品名、传输百分比、速度、剩余时间一律 `font-variant-numeric: tabular-nums`（Rust 侧是字节流，位数会跳，表格数字防抖动）。
- 字号严格按规格：产品名 14/600，设备标签 10，文件名 11，百分比 11/600，卡片元信息 9，拖拽提示 11。
- 不引入第三方字体。节点图是工具窗口，不是营销页。

## 三、布局姿态（Layout posture）

1. **画布锁死**：窗体 320×500，圆角 20，1px 描边，Background Blur 40，投影 `0 20px 60px rgba(0,0,0,.5)`。任何内容不得撑破这个盒子。
2. **节点坐标即契约**（窗口坐标）：本机中心 (160, 240) · 84px；手机 (66, 86) / 平板 (254, 86) · 52px；台式机 (160, 364) · 52px。台式机的 `bottom: 50px` 按「距节点图区底边 50px」解读，避免压到拖拽区。
3. **新拟物浮雕靠 inset 双向阴影**：外环 2px（设备 1.5px）半透明辉光色 → 内圆 6px / 4px 内缩 → 上左白 6% 高光 + 下右黑 30% 阴影。辉光走 `box-shadow` 0 blur 24 / 16，不用渐变。
4. **辉光即语义**：四种辉光色只用于设备类型识别，全窗不出现第五种彩色。进度条渐变 `#00D2D3 → #7C8CFF` 是唯一允许的线性渐变。
5. **一次只强调一件事**：空态只有自机 + spinner；发现态只有节点；传输态才出现连线 + 传输卡。三个状态不叠。

---

## 四、交互约定

- 拖拽区：44px 高、12px 圆角、1.5px dashed 15%。hover / dragover 时描边换 `glow/self` 并加 10% 同色底。
- 未选设备就投放文件 → 拒绝（抖动 + 提示），符合「点对点确认」的产品原则。
- 传输中：节点图上出现流动虚线（dash 动画，1s 循环），右下角浮出 200px 传输卡，`z-index` 高于节点图。
- 接收确认走系统级通知（Windows Toast / macOS 通知中心 / Android Notification），**不做应用内弹窗**（PRD §4.3）。
- 常驻后台：托盘（Win）/ 菜单栏（macOS）。关窗 = 收进托盘，不是退出。

---

## 五、禁止项

- 不用紫粉渐变背景、不用 emoji 图标、不用「左侧色条卡片」、不画手绘 SVG 人物。
- 不在窗口里放主题开关、平台切换、设备选择器等设计器控件。
- 不写「10× 更快」「99.9% 可用」这类没有来源的指标。
- 不在窗口内做接收确认弹窗（与 PRD 冲突）。
